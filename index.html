Grid-Following (GFL)

Uses a PLL to track grid angle. Stable at high SCR (strong grid). The PLL–impedance positive feedback loop causes instability below SCR ≈ 2. Dominant mode: complex pair near ±400–500 rad/s.

Grid-Forming (GFM droop)

Imposes voltage angle via static P–ω droop. No PLL → no SCR-dependent instability. Rightmost eigenvalue stays near −3 rad/s for all SCR values. Ideal for weak-grid operation.

Virtual Synchronous Machine

Replaces static droop with swing-equation dynamics. Provides inertial response. Trade-off: large T_α slows frequency response but improves damping. Stable for all SCR values tested.
